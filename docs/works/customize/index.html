01概念

换一种颜色，为什么要等一周

实体改装是重工艺：贴膜要手工对边，喷漆要打磨烤漆，轮毂换型要动平衡。而在数字世界，这些都是一次参数替换。

从「改装作业」到「改装预览」

这条短片的规则很严格：镜头不切、车不换位，只让颜色和部件变—— 观众一眼就能读懂「改装」发生在同一台车上。

制作上是生成 + 合成的混合管线：AI 生成车漆渐变的运动中间帧， 再逐帧合成回原片，保住车身结构、轮毂造型和水面倒影不动。 修整阶段做了去 UI 标注、背景细节重建与 4× 超分出 2K。

02车衣换色

颜色是流动的，不是贴上去的

蓝 → 紫 → 品红的渐变在单镜头内完成：车衣颜色沿着车身随镜头移动慢慢流过去，像液体一样可预览、可回退。

渐变的三个要求

  • ✓分界不生硬：色带沿车身曲面过渡，门缝和钣金缝不被色块盖住
  • ✓材质不跑偏：渐变只换色相，金属漆的闪片、反射和清漆层保持一致
  • ✓环境要接得住：倒影里的颜色和车身同步变化，水面不能穿帮

这三条让渐变换色在任何镜头角度都经得起暂停检查—— 颜色变了，但「这是一台金属漆的车」这件事从头到尾没变。

材质说明

车漆的质感来自三个层次：闪粉层随角度闪烁、色相层决定颜色、清漆层提供镜面反射。 换色只动中间的色相层，上下两层原样保留——所以渐变再夸张，漆面看起来依然是「真的漆」。

判断的标准也很朴素：轮毂、玻璃、镀铬件这些非车漆部分的反射 不跟着变；车身高光的位置只随视角移动，不随颜色移动。

03轮毂换造型

同屏四款轮毂，一键换型

画面左侧常驻四款轮毂缩略选项：多辐条运动款、密辐商务款、五辐镂空款、封闭低阻款——同一台车，四种性格。

配置器视角

轮毂是车辆形象里换装成本最低、感知差异最大的部件。短片中轮毂 选项和主画面同屏出现，选项被选中时轮毂造型与车身状态同步切换。

替换时控制了两件事：轮心位置与轮胎外径严格对齐（不然车身会 「跳」一下），辐条造型与刹车卡钳的遮挡关系保持正确。

04主视觉

从成片里长出来的海报

两条主视觉都从成片关键帧出发做后期：去标注与光标、背景四周外扩补细节、渐入云絮空气感、4× 超分出 2K。

05展开合拢

车是可以变形的

第三组镜头在讲形态：车辆展开露出结构、轮毂同屏可换，再收拢回整车——改装不止是换皮，也是让用户看见里面。

展开合拢镜头复用车辆结构分解的资产逻辑：覆盖件按装配关系 反向拆出，运动曲线用先慢后快的「吸气」节奏，收拢时留一次 轻微的回弹，让金属件有重量感。

展开过程中轮毂与车身分离悬浮、仍与轮拱保持对位—— 收拢瞬间轮毂对齐轮心复位，误差控制在一帧之内。

数字改装的终点不是一条短片，而是一套可交互的预览系统：颜色、轮毂、形态都是参数。这条片子是它的预告。
