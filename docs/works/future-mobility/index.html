cycle-00 共享出行概念车

针对城市出行效率低、模式单一、停车难等痛点，设计的一款模块化低底盘共享概念车，覆盖「研究 → 草图 → 原型 → 建模 → App 交互 → 结构 → 3D 打印实物」完整闭环。

01背景与洞察

城市出行的效率困境

未来城市出行需要解决「有限的基础设施与服务能力」和「快速增长的需求」之间的矛盾。

三个数字背后的矛盾

车辆约 95% 的时间停放在停车场；道路上约 60% 的车只有驾驶员一人；整个交通系统的平均利用效率不足设计效率的 2%。

资源闲置与需求错配同时存在——这是本项目的出发点。

问题归纳

通过桌面研究与观察，把现状问题收敛为三类：

  • 01出行模式分散·交通规划不便、拥堵频发，导航系统有待优化，多种方式之间缺乏衔接。
  • 02出行方式单一·缺少灵活的中间形态，难以覆盖「最后一公里」这类碎片化场景。
  • 03成本仍然偏高·共享出行的价格与流程门槛，让高频用户难以长期依赖。

竞品分析

MaaS 出行即服务

优势利用多元出行方式与大数据调度，资源利用率高

短板定制化服务导致价格偏高，受众面窄

出租车 / 网约车

优势可按需选择服务模式，价格相对合理

短板司机素质参差，存在安全隐患与体验波动

两者都无法同时满足「低成本 + 高灵活 + 可信赖」。这正是共享概念车的机会空间。

问卷数据验证

访谈之外补充发放问卷。使用时段上， 12–18 点占比最高（45.6%），6–12 点与 18–24 点接近，出行需求呈明显双峰。

高峰集中意味着共享车辆需要更强的调度能力，也印证了「自动接驾」的价值。

用户更在意什么

在注重因素中，性能（58.1%）与安全（53.2%）显著领先于价格与外观。

这决定了设计重心：先给用户一个「可靠、安全」的产品印象，再谈造型与性价比。

03设计定义

从旅程图到机会点

拆解「需求 → 规划 → 寻找 → 乘坐 → 到达 → 支付」六阶段用户旅程：情绪在规划与寻找阶段跌至最低，对应得到设计机会点。

用户旅程图

把访谈与问卷结论放进旅程图：每阶段的用户行为与痛点被逐条列出， 痛点最集中的四个环节，就是设计的四个机会点。

阶段用户行为痛点机会点
需求通勤上学、去商场、旅行出行方式不够灵活一体化的出行工具
规划确定目的地、选地铁站、带好钥匙公交卡频繁堵车、车厢拥挤实时路况分析与最优路线
寻找骑行 / 地铁 / 打车组合不愿挤公共交通，住处附近只有自行车车辆自动接驾
乘坐共享汽车解锁、清洁、线上约租座位不舒适、受天气影响、缺少私人空间优化车辆内饰与座舱体验
到达换乘、提前下车步行落点离目的地远灵活的落客点
支付单次 / 月卡结算、线上支付手机没信号时很尴尬开放多平台支付

设计定义

综合四个机会点，定义出一款模块化低底盘共享概念车 cycle-00：一体化出行工具，支持实时路况规划与自动接驾， 座舱体验针对短途乘坐优化，落客点灵活，支付开放多平台。

04造型推敲

草图 → 原型 → 数字模型

手绘推敲

先用大量手绘推敲比例关系：低底盘带来更低的重心与更大的乘坐空间， 四轮四角的布局让轮组可以模块化独立拆装。

确定概念方向

收敛出低底盘环舱概念：全景舱盖向上掀起，座舱与底盘完全解耦， 为后续模块化结构打下基础。

原型验证

在进入 3D 建模前，用 Arduino 制作履带验证小车，实车验证避障、 牵引与超声波控制逻辑——让「自动接驾」在早期就经过物理验证。

控制与传动

顶层布置控制模块：超声波避障 + 牵引控制双系统并行， 验证了小尺度下的路径跟随能力。

05交互流程

App 端四步闭环

App 端四步完成一次出行预约，车端配合平衡车接驳，形成十步完整使用循环。

支付

完整使用循环

从「发起需求」到「车辆归位」，车端与 App 端咬合成十步循环； 平衡车作为最后一公里接驳工具与车身集成，归还后自动进入充电待命。

06工程结构

模块化拆解

整车按三层结构拆解，模块之间独立装配，便于共享场景下的维护与更换。

三层结构

L1

座舱框架 + 座椅·环形框架结构，四人座布局

L2

车身覆盖件·前后覆盖件独立拆装

L3

底部模块化轮组·轮组与动力舱集成于底盘

细节设计

灯带沿轮组环绕，夜间行驶时兼具识别性与安全警示； 前脸保持极简开口，座舱内部以环屏承载全部交互。

07落地成果

从数字模型到 3D 打印实物

场景渲染

最终场景渲染验证产品气质：低底盘车身在城市街景中的存在感、 灯带在夜间的识别度，都通过渲染确认。

3D 打印实物

3D 打印 1:12 缩比模型，从多角度验证比例与细节， 完成「概念 → 数字 → 实物」的完整闭环。

这个项目让我完整走了一遍「研究 → 定义 → 造型 → 验证 → 落地」的设计流程，也让我确认了自己对出行产品与 3D 表达的兴趣方向。
