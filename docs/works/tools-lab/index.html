为什么车漆材质灯光棚演示片进行中

技术项目 · 汽车涂装 × UE 实时渲染 · 进行中

涂装实验室 PAINT LAB

车漆是实时渲染的「天花板考题」：多层材质、随角度流动的高光、清漆下的细节。这个项目用 UE5 从零搭一套灯光棚和四种车漆材质，做成一部可实时切换涂装的展示片——CMF 出身的设计师，用引擎把涂装讲透。

UE5车漆材质灯光棚SequencerCMF

01为什么做涂装

CMF 出身，引擎补全另一半

涂装是我最有发言权的材质：从工业设计的 CMF 标注，到用 UE5 把它实时渲出来。

从标注表到材质球

做巡检机器人项目时，我输出过完整的 CMF 标注：色号、材质、工艺。 但标注表只是一张纸——用引擎把工艺「渲出来」，才算真正理解它。

车漆是所有产品材质里最复杂的一类：色漆、闪粉、清漆三层叠加， 高光随角度流动。把它在 UE5 里做对，等于把实时材质系统整个打通。

02车漆材质体系

四种漆，四套参数

基于 UE5 Clear Coat 着色模型，每种涂装都是一组可切换的材质参数，而非一张贴图。

材质定义

材质不做成「一个好看的球」，而是做成一套可切换的系统：同一车型、同一机位，参数切换即换涂装。

四种车漆的同机位对比渲染（待补充）：

01金属漆 Metallic

色漆层 + 铝粉闪片 + 清漆层。Clear Coat 双层着色模型，闪粉用法线贴图在强光下呈现细密颗粒感

02珠光漆 Pearl

云母珠光粉的干涉变色：随观察角度在两个色相之间流动（如蓝→紫），用菲涅尔插值实现

03哑光漆 Matte

高粗糙度保留极浅的边缘高光，克制但高级——电动汽车上的主流选择

04清漆层 Clear Coat

所有亮光漆的「玻璃感」来源：单独控制清漆粗糙度与反射强度，是车漆质感的第一决定因素

浏览器里直接试：实时车漆 Shader

同一套思路的网页版——不依赖引擎，用 WebGL 手写着色器复现四种漆的物理结构： 金属漆的高频闪粉、珠光的菲涅尔干涉变色、哑光的粗糙度压平、清漆的独立第二高光。 与 UE5 材质一一对应，切换涂装、换颜色、拖动光源，材质表现实时变化。

WebGL 手写 Shader · 拖拽移动光源

金属漆 Metallic·色漆层 + 铝粉闪片 + 清漆层。拖动光源看闪粉颗粒——每一粒都是对法线的高频扰动，强光下呈细密闪光

注：Demo 为单个材质球（球体近似），UE5 项目里的车漆落在真实车型曲面上， 还包含清漆厚度、法线贴图闪粉与 Lumen 全局光照的叠加表现。

03灯光棚

车漆的唯一主角是光

黑棚 + 三条顶部光带 + 微反射地面——车漆高光的「拉丝流动」全部来自灯光设计。

棚内布置

纯黑棚 HDRI 打底，顶部三条长条形 Area Light 制造车漆上连续的高光拉丝； 三组光源做相位差动画，让光带在转台旋转时慢速流动——这是汽车 CG 质感的核心。

地面用微反射材质，车影交给 Lumen 全局光照自然生成，不贴假阴影。

04演示片

55 秒，六镜头，可切换涂装

对标行业级汽车 CG 展示片的分镜节奏，但不只展示成品——核心镜头是同机位实时切换四种涂装，展示的是系统能力。

分镜脚本

S10–5s · 开场

黑场中一道光带扫过，车漆轮廓渐显

S25–15s · 转台展示

整车 360° 旋转，金属漆在光带下流动

S315–27s · 涂装切换

同机位实时切换 4 种涂装，带工艺名称标注

S427–37s · 细节特写

logo / 轮毂 / 漆面微距，闪粉颗粒可见

S537–47s · 昼夜切换

日光棚 → 夜间氛围灯，Lumen 全局光照实时切换

S647–55s · 收尾

回到整车正面，标题淡入，配乐卡点

制作 Breakdown

每个镜头都会附制作过程：材质节点怎么连、灯光怎么布、 涂装切换用什么参数驱动——过程和结果一样重要。
